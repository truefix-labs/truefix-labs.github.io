02 / 報告

問題を報告する前に

秘密を含めず、再現に必要な情報をご提供ください。

  • TrueFix Studioの版/Buildと入手元。
  • OS、バージョン、CPUアーキテクチャ、該当する場合はモバイル端末機種。
  • 画面・手順、期待結果、実際の結果、発生時刻。
  • Provider、機能、市場、環境、伏字にしたClientInstance ID。
  • 安定エラーコード、Correlation ID、最小限の編集済みログ。
秘密を添付しないでください

API Key、Secret、パスワード、Cookie、秘密鍵、Access/Refresh Token、完全な口座識別子、不要な注文詳細、Providerの非公開Payloadを削除してください。画像・動画にも同じ情報が含まれ得ます。

03 / インストール

インストールと起動

署名されていないmacOSプレリリース

現在の直接ダウンロード版は署名・公証されていません。Applicationsへ移動後、そのアプリだけの隔離属性を消去します。

ターミナルコマンド

xattr -cr "/Applications/TrueFix Studio.app"

公式Releaseから意図して取得したBuildにのみ実行してください。sudoを使わず、/Applications全体や無関係なアプリを対象にしないでください。

Windows

x64 Windowsに合うSetup EXEまたはMSIを使用します。SmartScreenが表示されたら、公式Release由来であることと、提供される発行者/ハッシュ情報を確認してください。

Linux

ディストリビューションとアーキテクチャに合うAppImageまたはDebianパッケージを使用します。AppImageには実行権限が必要な場合があり、WebView依存関係は環境ごとに異なります。

常に公式ダウンロード欄の現行リンクを使用してください。ストア/テスト経由のiOS、Android、macOS、Windows版は同じ配布経路で更新してください。

04 / 診断

一般的なトラブル対処

  1. 正確なBuildを確認し、アプリを一度再起動します。
  2. About/診断で、秘密を表示せずに保存領域、Gateway、Providerの状態を確認します。
  3. 市場、銘柄マッピング、Provider、ClientInstance、環境、権限、鮮度を確認します。
  4. Agentではモデル設定、認可ツール、予算、承認、Runの安定エラーコードを確認します。
  5. 注文がuncertainなら再送せず、まず状態を照会・照合します。
  6. Simulatorまたは読取り専用で再試行し、製品状態とLive口座権限を切り分けます。

ログはOSアプリデータのtruefix-studio/logsにあります。日次アプリログはtruefix-studio.log.YYYY-MM-DD、Webアクセスログはaccess.log.YYYY-MM-DDです。共有前に伏字処理してください。

05 / WEB GATEWAY

WebとACMEのサポート

Web Gatewayはローカル管理者が明示設定するまで無効です。DNS A/AAAA、public_domains、完全なHTTPS public_base_url、証明書/SAN、許可Origin、信頼するProxy IP、Firewallを確認し、Let’s EncryptはStagingで先に試してください。

  • 非loopback ListenerにはHTTPSが必須です。
  • 認証情報に懸念があればパスワードを変更し、全Webセッションを失効させます。
  • 到達不能なAAAAを削除し、不安定なフォールバックを避けます。
  • 完全な手順は利用ガイドのWeb GatewayとACMEをご覧ください。

06 / データ管理

ローカルデータを削除する

現行アプリはTrueFixクラウドアカウントを作成しません。先にアプリを終了し、元サービスでProvider/API認証情報を失効させてください。必要なものはバックアップしてください。削除は元に戻せません。

設定

~/.truefix-studioを削除するとローカル設定、Provider/AI認証情報、保存されているACME状態が削除されます。

アプリデータ

OSのアプリデータにあるtruefix-studioを削除します。DBの代表例はmacOSの~/Library/Application Support/truefix-studio、Windowsの%LOCALAPPDATA%\truefix-studio、Linuxの${XDG_DATA_HOME:-~/.local/share}/truefix-studioです。ログは標準アプリデータを使い、Windowsでは別途%APPDATA%\truefix-studio\logsにある場合があります。削除前にAbout/診断ですべての実際の場所を確認してください。

Webセッション

Web Gatewayを無効にし、端末/セッション管理でログアウトまたは失効させます。ローカルweb-auth.sqlite3の削除で保存済みRefresh Sessionは無効になります。

本サイト

ブラウザーでtruefix-labs.comのサイトデータを消去するとtruefix.language設定が削除されます。

アンインストールだけでは設定やデータが残る場合があります。Provider、AIサービス、GitHub等へ送信済みのデータは各サービスで削除してください。TrueFix Labsへ直接送った個人情報の削除はメールで依頼できます。

07 / プライバシー

プライバシーとセキュリティの申請

データ分類、送信先、保存、保持、管理方法はプライバシーポリシーをご覧ください。脆弱性は最小限のPoCを添えてメールで非公開報告してください。他人の口座・データへのアクセス、サービス妨害、調査前の悪用可能情報の公開は禁止します。

08 / 提供状況

製品とストアでの提供

機能はOS、Build、ストア経路、Provider、市場、Entitlement、法域で異なります。Adapterの掲載は全機能の提供を意味しません。本製品は投資助言を提供せず、ブローカー/取引所のサポート、開示、取引記録に代わりません。

本ページはApple App Store、Google Play、Microsoft Store等のSupport URLとして使用できます。課金、返金、互換性、ストアアカウントは配布元ストアの対応も必要な場合があります。
