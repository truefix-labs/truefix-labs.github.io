03 / 설치

설치와 실행

서명되지 않은 macOS 출시 전 빌드

현재 직접 다운로드 빌드는 서명 또는 공증되지 않았습니다. Applications로 옮긴 후 해당 앱에 대해서만 격리 속성을 지우십시오.

터미널 명령

xattr -cr "/Applications/TrueFix Studio.app"

공식 Release에서 의도적으로 받은 빌드에만 실행하십시오. sudo를 사용하거나 /Applications 전체 또는 무관한 앱을 대상으로 삼지 마십시오.

Windows

x64 Windows에 맞는 Setup EXE 또는 MSI를 사용하십시오. SmartScreen이 표시되면 공식 Release 파일인지 확인하고 제공된 게시자/해시 정보를 검토하십시오.

Linux

배포판과 아키텍처에 맞는 AppImage 또는 Debian 패키지를 사용하십시오. AppImage에는 실행 권한이 필요할 수 있고 WebView 의존성은 배포판마다 다릅니다.

항상 공식 다운로드 영역의 최신 링크를 사용하십시오. 스토어/테스트 채널의 iOS, Android, macOS, Windows 빌드는 같은 채널로 설치·업데이트하십시오.

04 / 진단

일반 문제 해결 순서

  1. 정확한 Build를 확인하고 앱을 한 번 재시작합니다.
  2. About/진단에서 자격 증명을 노출하지 않고 저장소, Gateway, Provider 상태를 확인합니다.
  3. 시장, 종목 매핑, Provider, ClientInstance, 환경, 권한, 최신성을 확인합니다.
  4. Agent 오류는 모델 설정, 승인된 도구, 예산, 승인과 Run 안정 오류 코드를 확인합니다.
  5. 주문이 uncertain이면 다시 제출하지 말고 먼저 상태를 조회·조정합니다.
  6. Simulator 또는 읽기 전용으로 재시도해 제품 상태와 Live 계정 권한을 분리합니다.

로그는 OS 앱 데이터의 truefix-studio/logs에 있습니다. 일별 앱 로그는 truefix-studio.log.YYYY-MM-DD, Web 접속 로그는 access.log.YYYY-MM-DD입니다. 공유 전에 마스킹하십시오.

05 / WEB GATEWAY

Web과 ACME 지원

Web Gateway는 로컬 운영자가 명시적으로 설정하기 전까지 꺼져 있습니다. DNS A/AAAA, public_domains, 완전한 HTTPS public_base_url, 인증서/SAN, 허용 Origin, 신뢰 Proxy IP, 방화벽을 확인하고 Let’s Encrypt는 Staging에서 먼저 시험하십시오.

  • non-loopback Listener에는 HTTPS가 필수입니다.
  • 자격 증명이 의심되면 접근 비밀번호를 변경하고 모든 Web 세션을 폐기합니다.
  • 도달하지 않는 AAAA를 제거해 불안정한 fallback을 피합니다.
  • 전체 절차는 사용 가이드의 Web Gateway와 ACME를 참조하십시오.

06 / 데이터 제어

로컬 데이터 삭제

현재 앱은 TrueFix 클라우드 계정을 만들지 않습니다. 앱을 먼저 종료하고 원래 서비스에서 Provider/API 자격 증명을 폐기하십시오. 필요한 것은 백업하십시오. 삭제는 되돌릴 수 없습니다.

설정

~/.truefix-studio를 삭제하면 로컬 설정, Provider/AI 자격 증명과 저장된 ACME 상태가 삭제됩니다.

앱 데이터

OS 앱 데이터의 truefix-studio 폴더를 삭제합니다. DB의 일반적인 위치는 macOS ~/Library/Application Support/truefix-studio, Windows %LOCALAPPDATA%\truefix-studio, Linux ${XDG_DATA_HOME:-~/.local/share}/truefix-studio입니다. 로그는 표준 앱 데이터 위치를 사용하며 Windows에서는 별도 %APPDATA%\truefix-studio\logs에 있을 수 있습니다. 삭제 전 About/진단에서 모든 실제 경로를 확인하십시오.

Web 세션

Web Gateway를 비활성화하고 기기/세션 제어로 로그아웃하거나 폐기합니다. 로컬 web-auth.sqlite3 삭제는 저장된 Refresh Session을 무효화합니다.

본 웹사이트

브라우저에서 truefix-labs.com 사이트 데이터를 지우면 truefix.language 설정이 삭제됩니다.

앱 제거만으로 설정이나 데이터가 남을 수 있습니다. Provider, AI 서비스, GitHub 등에 보낸 데이터는 각 서비스에서 삭제해야 합니다. TrueFix Labs에 직접 보낸 개인정보 삭제는 이메일로 요청하십시오.

08 / 제공 범위

제품과 앱 마켓 제공

기능은 OS, Build, 스토어 채널, Provider, 시장, Entitlement, 관할 지역에 따라 다릅니다. Adapter 표시가 모든 기능 제공을 뜻하지 않습니다. 본 제품은 투자 조언을 제공하지 않으며 브로커/거래소 지원, 공개 또는 거래 기록을 대체하지 않습니다.

본 페이지는 Apple App Store, Google Play, Microsoft Store 등에서 Support URL로 사용할 수 있습니다. 결제, 환불, 호환성, 스토어 계정은 배포한 스토어의 지원도 필요할 수 있습니다.
