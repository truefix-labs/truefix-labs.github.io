TRUEFIX STUDIO USER GUIDE

Operate the current pre-release safely

This public guide explains first launch, unsigned macOS installation, Provider and ClientInstance configuration, instruments and market data, order Review and RiskGuard, portfolios, Intelligence, authorized Agent tools, deterministic Quant automation, Web Gateway and ACME, audit operations, and troubleshooting.

  • Start with Simulator, Demo, Testnet, or Paper before using a Live account.
  • Verify Provider, ClientInstance, environment, account, instrument mapping, freshness, and permissions before every consequential action.
  • Treat unavailable, stale, degraded, rejected, reconciling, and uncertain as distinct states.
  • Keep credentials in local settings and never place secrets in Agent conversations, URLs, screenshots, or support tickets.
