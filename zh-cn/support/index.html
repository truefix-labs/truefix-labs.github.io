02 / 报告

提交问题之前

请提供足够的复现信息，同时确保报告中没有秘密：

  • TrueFix Studio 版本/Build 及获取渠道。
  • 操作系统、版本、CPU 架构；如适用，也请提供移动设备型号。
  • 相关页面或流程、预期结果、实际结果和大致时间。
  • Provider、能力、市场、环境及已脱敏的 ClientInstance ID。
  • 稳定错误码、Correlation ID 和最小化的脱敏日志片段。
绝不要附上秘密

删除 API Key、Secret、密码、Cookie、私钥、Access/Refresh Token、完整账户标识符、不准备披露的订单细节和 Provider 原始私有 Payload。截图与录屏也可能包含这些信息。

03 / 安装

安装与启动

macOS 未签名首版发布前版本

当前直接下载版本尚未签名或公证。将应用移至“应用程序”后，只为该应用清除隔离属性：

终端命令

xattr -cr "/Applications/TrueFix Studio.app"

仅对你主动从官方 Release 下载的版本运行此命令。不要使用 sudo，不要把目标设为整个 /Applications，也不要递归处理无关应用。

Windows

使用与 x64 Windows 匹配的 Setup EXE 或 MSI。如出现 SmartScreen，请先核对文件来自官方 Release，并检查该 Release 提供的发布者/哈希信息。

Linux

使用与发行版和架构匹配的 AppImage 或 Debian 包；AppImage 可能需要执行权限，桌面集成和 WebView 依赖因发行版而异。

请始终使用官方下载区域的当前链接；Nightly 的文件名和大小会变化。通过商店或测试渠道获得的 iOS、Android、macOS 或 Windows 版本，应继续通过同一渠道安装和更新。

04 / 诊断

通用故障排查路径

  1. 确认准确 Build，并重启应用一次。
  2. 在“关于/诊断”查看存储、Gateway 和 Provider 健康状态，但不要暴露凭据。
  3. 核对市场、标的映射、Provider、ClientInstance、环境、权限与新鲜度。
  4. Agent 失败时检查模型配置、授权工具、预算、审批和 Run 的稳定错误码。
  5. 订单状态为 uncertain 时不要盲目重提；先查询并对账。
  6. 在 Simulator 或只读上下文中重试，以区分产品状态与实盘账户权限问题。

应用日志位于操作系统应用数据目录的 truefix-studio/logs。应用日志按日记录为 truefix-studio.log.YYYY-MM-DD，Web 访问日志为 access.log.YYYY-MM-DD。分享前必须脱敏。

05 / WEB GATEWAY

Web 与 ACME 支持

Web Gateway 只有在本地运营者明确配置后才会启用。远程访问需核对 DNS A/AAAA、public_domains、完整 HTTPS public_base_url、证书/SAN 匹配、Allowed Origins、可信代理 IP 与防火墙可达性。Let’s Encrypt 应先在 Staging 环境验证。

  • 非 loopback 监听必须使用 HTTPS，不能向网络暴露仅 HTTP 的监听器。
  • 怀疑凭据泄露时，轮换访问密码并撤销所有 Web 会话。
  • 无法到达的 AAAA 应移除，不要依赖客户端不可预测的降级。
  • 完整流程见使用指南的 Web Gateway 与 ACME。

06 / 数据控制

删除本地数据

当前应用不创建 TrueFix 云端账户。删除本地 Profile 前请先退出 TrueFix Studio，并在原服务撤销 Provider/API 凭据。提前备份需要保留的内容；删除不可恢复。

配置

删除 ~/.truefix-studio 可移除本地设置及 Provider/AI 凭据，ACME 状态也可能存于此处。

应用数据

删除操作系统应用数据位置中的 truefix-studio 文件夹。数据库常见位置为 macOS 的 ~/Library/Application Support/truefix-studio、Windows 的 %LOCALAPPDATA%\truefix-studio、Linux 的 ${XDG_DATA_HOME:-~/.local/share}/truefix-studio。日志使用标准应用数据位置，在 Windows 上可能另位于 %APPDATA%\truefix-studio\logs。删除前请在“关于/诊断”确认全部实际路径。

Web 会话

删除前先停用 Web Gateway，并通过设备/会话控制退出或撤销会话。删除本地 web-auth.sqlite3 会使持久 Refresh Session 失效。

本网站

在浏览器中清除 truefix-labs.com 的网站数据，即可删除 truefix.language 语言偏好。

卸载应用可能保留配置或应用数据。已发送给 Provider、AI 服务、GitHub 或其他第三方的数据，需使用相应服务的控制进行删除。删除直接发给 TrueFix Labs 的个人信息，请向支持邮箱发送请求。
