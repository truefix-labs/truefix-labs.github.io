AI 전략 생성과 배포

거래 규칙을 AI에게 설명하세요.
생성하고, 테스트하고, 배포하세요.

Desktop 전략 엔지니어링에서 Agent에게 목표를 설명합니다. 전략과 테스트 결과를 확인한 뒤 배포 화면에서 제안을 검토하고 승인해 시작합니다.

AI에게 요청하는 예시

이동평균 교차 전략 초안을 만들어 주세요. 필요한 데이터, 진입·청산 조건과 리스크 한도를 명시하고 과거 데이터로 검증해 주세요. 배포 전에는 제 확인을 요청하세요.
  1. 01

    AI로 초안 생성

    종목, 규칙과 제약을 설명하고 추가 확인 질문에 답합니다.

  2. 02

    검증과 테스트

    전략 버전을 확인하고 백테스트나 리플레이로 동작과 리스크를 살펴봅니다.

  3. 03

    배포안 검토

    버전, 데이터 출처, 계정, 환경과 리스크 한도를 확인합니다.

  4. 04

    승인 후 시작

    Desktop에서 배포안을 승인하고 승인된 배포를 명시적으로 시작합니다.

  5. 05

    모니터링과 일시정지

    실행 상태, 로그와 결정을 확인하고 필요하면 일시정지하거나 중지합니다.

전략 생성만으로 실거래가 시작되지는 않습니다. 배포 생성과 Live 활성화는 Desktop에서 수행합니다. H5는 모니터링, 결정별 승인, 일시정지와 중지를 지원하며 실행에는 계정 권한과 리스크 검사가 적용됩니다.
