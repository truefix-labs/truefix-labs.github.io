TRUEFIX STUDIO USER GUIDE

Start with the basics

This guide explains how to install TrueFix Studio, connect a broker, exchange, or market-data service, use the AI assistant, test strategies, and check a trading action before sending it. Advanced browser and server settings are kept in separate sections.

  • Start in read-only or simulation mode. These modes do not use real money.
  • Before a real trade, check the connected service, account, test or live mode, product, price, fees, and risk.
  • If data is old, missing, or uncertain, stop and refresh it before continuing.
  • Enter passwords and API keys only in the app's settings. Never put them in AI conversations, URLs, screenshots, or support messages.
