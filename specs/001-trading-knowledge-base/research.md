# Research Notes

## Existing site

The repository is a static GitHub Pages site. The existing generator creates localized product pages, canonical URLs, hreflang links, and a comprehensive sitemap. The homepage uses runtime translations for product copy but its HTML source already contains meaningful content and JSON-LD.

## Crawler policy

OpenAI documents `OAI-SearchBot` as the crawler that makes public content eligible for ChatGPT Search snippets and citations. OpenAI distinguishes this from `GPTBot`, which is a training signal. Anthropic documents `Claude-SearchBot` for search quality and `Claude-User` for user-directed access. The site policy allows both search crawlers and GPTBot.

## Content policy

The TrueFix Studio project README supports claims about provider-neutral contracts, canonical instruments, explicit account and environment scope, risk and approval boundaries, unknown order recovery, and simulation. Broker capability claims are intentionally conservative and link to official provider documentation.
