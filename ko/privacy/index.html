페이지 목차

개요적용 범위와 책임자처리 정보서비스와 공유저장과 보관사용자 선택보안과 아동변경과 문의

개인정보 핵심 안내

  • TrueFix Studio는 로컬 우선 방식이며, 현재 앱은 TrueFix 클라우드 계정을 요구하거나 생성하지 않습니다.
  • Provider 자격 증명, 작업 공간, Agent 세션, 시장 데이터, 거래 기록과 로그는 앱이 실행되는 기기에 저장됩니다.
  • 브로커, 거래소, 데이터 소스 또는 AI 서비스는 사용자가 해당 서비스를 구성하고 사용할 때만 요청 수행에 필요한 데이터를 받습니다.
  • 개인정보를 판매하거나 행동 광고를 제공하지 않습니다. 웹사이트는 Google Analytics로 방문 현황을 측정하지만 앱에는 제품 분석 기능이 없습니다.

01 / 범위

적용 범위와 책임 주체

본 방침은 TrueFix Studio 공개 웹사이트, 다운로드 앱, 선택형 Web Gateway 및 사용자가 TrueFix Labs에 자발적으로 보내는 지원 정보에 적용됩니다. “TrueFix”, “당사”는 TrueFix Labs를 의미합니다.

브로커, 거래소, 시장 데이터 소스, AI 모델 서비스, GitHub와 Google은 각자의 약관과 개인정보 처리방침에 따라 독립적으로 정보를 처리하며 당사는 그 관행을 통제하지 않습니다.

02 / 정보

제품이 처리하는 정보

공개 웹사이트

언어 설정은 브라우저 localStorage의 truefix.language에 저장됩니다. Google Analytics는 페이지 방문을 측정하며 식별자, 대략적인 위치, 기기와 브라우저 정보, 유입 경로, URL과 방문 시간을 처리하고 분석 쿠키를 설정할 수 있습니다. 광고 개인화에는 사용하지 않습니다. GitHub Pages와 Google Fonts도 표준 요청 정보를 수신하며 다운로드 영역은 GitHub의 공개 Release 메타데이터를 요청합니다.

로컬 앱

사용 기능에 따라 설정, Provider와 AI 자격 증명, 종목 매핑, 시장·리서치 데이터, 작업 공간, 관심 목록, Agent 대화·도구 기록, 전략, 주문, 포지션, 리스크·감사 증거, 진단 로그를 로컬에 저장합니다.

Provider·AI 연결

연동을 활성화하면 요청에 필요한 식별자, 쿼리, 프롬프트, 계정 지시, 인증 데이터 또는 주문이 전송됩니다. 수신자와 필드는 구성한 Provider, 기능, 작업에 따라 달라집니다.

선택형 Web Gateway

로컬 운영자가 활성화하면 로그인과 세션 정보를 처리하고 IP, User-Agent, 리퍼러, Host, 요청 경로, 응답 상태, 시간을 포함할 수 있는 접속/보안 로그를 기록합니다. Refresh Token, IP, User-Agent 지문은 로컬 인증 DB에 해시로 저장되고 브라우저에는 HttpOnly 세션 쿠키가 저장될 수 있습니다.

기술 지원

문의 시 사용한 주소 또는 계정, 메시지, 자발적으로 제공한 진단 자료나 첨부 파일을 받습니다. API Key, 비밀번호, 쿠키, 개인 키, 전체 계좌번호, 미삭제 금융 기록을 보내지 마십시오.

금융 데이터

시장, 포트폴리오, 계정, 주문 정보는 민감할 수 있으며 요청한 워크스테이션 기능을 제공하기 위해 처리됩니다. 본 제품은 건강, 연락처, 정밀 위치, 광고 ID 또는 앱 간 활동을 수집하도록 설계되지 않았습니다.

03 / 서비스

정보의 이용과 공개

정보는 요청한 기능 제공, 보안과 세션 유지, 감사 가능성 보존, 장애 진단 및 지원 답변을 위해 사용합니다. 판매하거나 대여하지 않습니다.

사용자 지정 서비스

명시적으로 구성하거나 선택한 브로커, 거래소, 데이터 공급자, 뉴스/인텔리전스 소스, AI 모델 Provider, DNS/ACME 서비스 등에 전송됩니다. 해당 서비스는 다른 국가에서 처리하거나 사용자와의 계약에 따라 보관할 수 있습니다.

웹사이트 인프라와 방문 분석

공개 사이트는 GitHub Pages에서 호스팅되고 Google Fonts와 Google Analytics를 사용합니다. Google은 자체 약관과 개인정보 처리방침에 따라 분석 데이터를 처리합니다. GitHub Discussions와 Releases 링크에는 GitHub의 개인정보 처리방침이 적용됩니다.

법률과 안전

법률 준수, 사용자 보호, 악용 조사 또는 TrueFix Labs의 보안과 권리 보호에 합리적으로 필요한 경우, 사용자가 보낸 정보를 필요한 범위에서 보존하거나 공개할 수 있습니다.

04 / 저장

로컬 저장, 자격 증명과 보관

일상적인 설정은 앱 화면에서 변경하고 앱이 기기에 저장합니다. 아래 경로는 저장 위치 설명과 백업 또는 데이터 삭제 시 확인하기 위한 것입니다.

설정은 기본적으로 ~/.truefix-studio/config.toml에, DB와 일별 로그는 OS 로컬 앱 데이터의 truefix-studio에 저장됩니다. Provider 자격 증명은 소유자만 읽을 수 있는 로컬 설정에 저장되고 일반 UI와 진단에서 마스킹됩니다. 현재 출시 전 버전은 OS Keychain을 사용하지 않으므로 기기와 파일 시스템 보안이 중요합니다.

로컬 기록은 사용자가 삭제하거나 앱 제거 후 데이터를 삭제하거나 명시된 보관/압축 규칙이 적용될 때까지 남습니다. 로그의 일별 순환은 자동 삭제를 의미하지 않습니다. 제3자와 지원 서비스의 보관은 각 정책을 따릅니다.

05 / 제어

사용자의 개인정보 선택

  • 요청을 받고 싶지 않은 Provider나 AI 서비스를 구성하지 않습니다.
  • 적절한 경우 읽기 전용, Paper, Demo, Testnet, Simulator를 사용하고 원래 서비스에서 자격 증명을 폐기합니다.
  • Web Gateway 비활성화, 브라우저 로그아웃, 개별 Web 기기 폐기, 접근 비밀번호 변경 또는 로컬 세션 저장소 삭제를 사용합니다.
  • 기술 지원 페이지 안내에 따라 로컬 설정, DB, 로그와 웹사이트 언어 설정을 삭제합니다.
  • 브라우저 설정에서 분석 쿠키를 제한하거나 삭제하고, 사용 가능한 Google Analytics 차단 도구를 이용할 수 있습니다.
  • TrueFix Labs에 직접 보낸 개인정보의 열람·삭제는 당사에 요청할 수 있으며 본인 확인이 필요할 수 있습니다.
TrueFix 클라우드 계정 없음

현재 버전은 호스팅형 TrueFix 사용자 계정을 만들지 않으므로 Google Play 웹 계정 삭제 흐름은 적용되지 않습니다. 향후 계정 생성을 도입하면 배포 전에 본 방침과 삭제 제어를 업데이트합니다.

06 / 보안

보안과 아동

로컬 사용자 전용 권한, 자격 증명 마스킹, 범위 기반 권한, Web Refresh Token과 클라이언트 지문 해시, 단기 Access Token, 세션 폐기, Host/Origin 검사, non-loopback Web Gateway HTTPS 의무화 등을 사용합니다. 완전히 안전한 시스템은 없으므로 기기, 설정, 백업, Provider 자격 증명을 보호하십시오.

TrueFix Studio는 전문 금융 워크스테이션이며 아동을 대상으로 하지 않습니다. 아동의 개인정보를 의도적으로 요청하지 않습니다. 사용자는 각 브로커, 거래소, 스토어와 관할 지역의 연령 및 자격 요건을 충족해야 합니다.

07 / 문의

변경과 연락처

기능, 연결 서비스 또는 법적 요구가 바뀌면 본 방침을 업데이트할 수 있습니다. 상단 날짜와 버전이 현재 방침을 나타내며 중요한 변경은 적절한 제품 또는 웹사이트 공지로 안내합니다.

본 페이지는 현재 출시 전 버전을 설명하고 스토어 공개의 정확성을 돕기 위한 것입니다. 법률 자문이나 실제 제출 바이너리에 맞춘 각 스토어 App Privacy/Data safety 설문을 대신하지 않습니다.
