隐私 / 你的数据

哪些数据留在设备上，
哪些数据会发送出去。

用容易理解的语言说明 TrueFix 会处理哪些信息，以及你可以如何控制这些信息。

最后更新 2026-09-05Version 1.1

本页目录

概要适用范围与责任方处理的信息服务与共享存储与保留你的选择安全与未成年人变更与联系

隐私要点

  • TrueFix Studio 采用本地优先架构；当前版本不要求也不会创建 TrueFix 云端账户。
  • Provider 凭据、工作区、Agent 会话、行情、交易记录与日志保存在运行应用的设备上。
  • 只有当你配置并使用某个券商、交易所、数据源或 AI 服务时，应用才会向该服务发送完成请求所需的数据。
  • 我们不出售个人数据，也不投放行为广告。官网使用 Google Analytics 统计访问情况；应用本身不包含产品分析功能。

01 / 范围

适用范围与责任方

本政策适用于 TrueFix Studio 官网、可下载应用、可选的 Web Gateway，以及你主动发送给 TrueFix Labs 的支持信息。“TrueFix”“我们”指 TrueFix Labs。

券商、交易所、行情数据源、AI 模型服务、GitHub 与 Google 均依据各自条款和隐私政策独立处理信息。TrueFix Studio 帮助你连接这些服务，但无法控制其独立的数据实践。

02 / 信息

产品处理的信息

公开网站

语言偏好以 truefix.language 保存在浏览器 localStorage。Google Analytics 会统计页面访问，并可能处理标识符、大致位置、设备与浏览器信息、来源页面、访问 URL 和时间，也可能设置分析 Cookie。网站不用于个性化广告。GitHub Pages 和 Google Fonts 也会接收标准请求信息；下载区域还会从 GitHub 请求公开的 Release 元数据。

本地应用

根据你使用的功能，应用会在本地存储设置、Provider 与 AI 凭据、标的映射、行情与研究数据、工作区、自选列表、Agent 对话与工具记录、策略、订单、持仓、风控与审计证据及诊断日志。

Provider 与 AI 连接

当你启用某项集成时，应用会发送完成请求所需的标识符、查询、Prompt、账户指令、认证数据或订单。接收方和字段取决于你配置的 Provider、能力与具体操作。

可选 Web Gateway

本地运营者启用 Web Gateway 后，它会处理登录和会话信息，并写入可能包含 IP、User-Agent、来源页、Host、请求路径、响应状态和耗时的访问/安全日志。Refresh Token、IP 与 User-Agent 指纹以哈希形式存于本地认证数据库；浏览器可能保存 HttpOnly 会话 Cookie。

技术支持

联系我们时，我们会收到你使用的地址或账户、消息，以及你主动提供的诊断或附件。请勿发送 API Key、密码、Cookie、私钥、完整账号或未脱敏的财务记录。

财务数据

行情、组合、账户和订单信息可能属于敏感信息；处理这些信息是为了完成你请求的工作站功能。TrueFix Studio 并非为收集健康、通讯录、精确位置、广告标识符或跨应用活动而设计。

03 / 服务

信息如何使用与披露

信息用于提供你请求的功能、维护安全与会话、保留可审计性、诊断故障和回复支持请求。我们不会出售或出租这些信息。

用户指定的服务

信息会发送到你明确配置或选择的券商、交易所、数据供应商、新闻/情报源、AI 模型 Provider、DNS/ACME 服务或其他端点。这些服务可能在其他国家或地区处理数据，并按与你之间的协议保留数据。

网站基础设施与访问分析

官网托管于 GitHub Pages，从 Google Fonts 加载字体，并使用 Google Analytics。Google 会根据自己的条款和隐私政策处理分析数据。GitHub Discussions 和 Releases 链接会带你前往 GitHub，这些服务按各自隐私政策处理收到的信息。

法律与安全

为遵守法律、保护用户、调查滥用或维护 TrueFix Labs 的安全与权利，我们可能保留或披露你发送给我们的信息，并将范围限制在合理必要的程度。

04 / 存储

本地存储、凭据与保留

配置默认存于 ~/.truefix-studio/config.toml；应用数据库和按日滚动日志存于操作系统应用数据位置的 truefix-studio 下。Provider 凭据保存在仅当前用户可读的本地配置中，并会在常规界面投影与诊断中脱敏。当前首版发布前版本不使用操作系统 Keychain 存储这些凭据，因此设备和文件系统安全十分重要。

本地记录会保留到你主动删除、卸载并删除应用数据，或产品明确的保留/压缩规则生效。日志文件按日滚动不代表会自动删除。发送到第三方的数据遵循第三方的保留政策；支持消息会保留在你使用的联系服务中，直至按其控制删除或已无合理保留需要。

05 / 你的控制

你的隐私选择

  • 不要配置你不希望接收请求的 Provider 或 AI 服务。
  • 在适当情况下使用只读、Paper、Demo、Testnet 或 Simulator，并在原服务撤销凭据。
  • 停用 Web Gateway、退出浏览器、撤销单个 Web 设备、轮换访问密码或清理本地会话库。
  • 按照技术支持页说明删除本地设置、数据库、日志与官网语言偏好。
  • 可以通过浏览器设置限制或清除分析 Cookie，也可以使用 Google 提供的 Analytics 停用工具。
  • 如需访问或删除你直接发送给 TrueFix Labs 的个人信息，请联系我们；我们可能需要核验请求。
没有 TrueFix 云端账户

当前版本不会创建托管的 TrueFix 用户账户，因此 Google Play 的网页账户删除流程不适用于本版本。如未来增加账户创建，我们会在分发前更新本政策与删除控制。

06 / 安全

安全与未成年人

我们采用本地仅用户权限、凭据脱敏、范围化授权、Web Refresh Token 与客户端指纹哈希、短期 Access Token、会话撤销、Host/Origin 校验，以及非 loopback Web Gateway 强制 HTTPS 等措施。任何系统都无法保证绝对安全；请保护设备、配置、备份和 Provider 凭据。

TrueFix Studio 是专业金融工作站，并非面向未成年人。我们不会有意索取未成年人的个人信息。用户必须满足所使用券商、交易所、应用市场与司法辖区的年龄及资格要求。

07 / 联系

变更与联系方式

当产品功能、连接服务或法律要求变化时，我们可能更新本政策。顶部日期和版本用于标识当前政策；重大变更会通过适当的产品或网站通知呈现。

本页描述当前首版发布前版本，用于帮助应用市场获得准确披露；它不能替代法律建议，也不能替代根据实际提交的二进制文件填写各市场的 App Privacy/Data safety 问卷。
