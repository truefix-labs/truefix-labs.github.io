概要範囲と管理者取扱う情報サービスと共有保存と保持利用者の選択安全性と未成年者変更と連絡先

プライバシーの要点

  • TrueFix Studioはローカル優先です。現行アプリはTrueFixクラウドアカウントを必要とせず、作成もしません。
  • Provider認証情報、ワークスペース、Agentセッション、市場データ、取引記録、ログはアプリを実行する端末に保存されます。
  • ブローカー、取引所、データソース、AIサービスへは、利用者がそのサービスを設定し使用した場合にのみ、要求の実行に必要なデータが送信されます。
  • 個人データの販売、行動広告、現行サイトやアプリへの自社製品分析の組込みは行いません。

01 / 範囲

適用範囲と責任主体

本ポリシーはTrueFix Studioの公開サイト、ダウンロード可能なアプリ、任意のWeb Gateway、およびTrueFix Labsへ任意に送信するサポート情報に適用されます。「TrueFix」「当社」はTrueFix Labsを指します。

ブローカー、取引所、市場データ提供元、AIモデルサービス、GitHub、Googleは各自の規約とプライバシーポリシーに基づき独立して情報を処理します。当社はそれらの独立した運用を管理しません。

02 / 情報

製品が取り扱う情報

公開サイト

言語設定はブラウザーのlocalStorageにtruefix.languageとして保存されます。広告・分析Cookieは設定しません。GitHub PagesとGoogle Fontsは、サービス提供に必要なIPアドレス、ブラウザーヘッダー、URL、時刻等の標準リクエスト情報を受信します。ダウンロード欄はGitHubの公開Releaseメタデータも取得します。

ローカルアプリ

使用機能に応じ、設定、Provider・AI認証情報、銘柄マッピング、市場・調査データ、ワークスペース、ウォッチリスト、Agent会話・ツール記録、戦略、注文、ポジション、リスク・監査証跡、診断ログをローカル保存します。

Provider・AI接続

連携を有効にすると、要求に必要な識別子、クエリ、プロンプト、口座指示、認証情報または注文が送信されます。送信先と項目は設定したProvider、機能、操作により異なります。

任意のWeb Gateway

ローカル管理者が有効化した場合、ログイン・セッション情報を処理し、IP、User-Agent、参照元、Host、パス、状態、処理時間を含み得るアクセス/セキュリティログを書き込みます。Refresh Token、IP、User-Agentの指紋はローカル認証DBにハッシュで保存され、ブラウザーにはHttpOnly Cookieが保存される場合があります。

サポート

連絡時には、利用したアドレスまたはアカウント、メッセージ、任意に添付した診断情報を受信します。API Key、パスワード、Cookie、秘密鍵、完全な口座番号、未編集の財務記録は送らないでください。

金融データ

市場、ポートフォリオ、口座、注文情報は機微な場合があります。要求されたワークステーション機能のために処理されます。本製品は健康、連絡先、正確な位置、広告ID、アプリ横断活動を収集する目的で設計されていません。

03 / サービス

情報の利用と開示

情報は、要求された機能の提供、セキュリティとセッションの維持、監査可能性、障害診断、サポート対応に利用します。販売または貸与はしません。

利用者が指定するサービス

明示的に設定・選択したブローカー、取引所、データベンダー、ニュース/インテリジェンス源、AIモデルProvider、DNS/ACMEサービス等に送信されます。各サービスは他国で処理し、利用者との契約に従って保持する場合があります。

サイト基盤

公開サイトはGitHub Pagesでホストされ、Google Fontsを読み込みます。GitHub DiscussionsとReleasesへのリンク先ではGitHubのポリシーが適用されます。

法令と安全

法令遵守、利用者保護、不正調査、TrueFix Labsの安全・権利保護に合理的に必要な場合、送信された情報を必要な範囲に限り保持または開示することがあります。

04 / 保存

ローカル保存、認証情報、保持

設定は既定で~/.truefix-studio/config.tomlに、DBと日次ログはOSのローカルアプリデータ内truefix-studioに保存されます。Provider認証情報は所有者のみ読取り可能なローカル設定に置かれ、通常のUIと診断では伏せられます。現行プレリリースはOS Keychainを使用しないため、端末とファイルシステムの保護が重要です。

ローカル記録は、利用者が削除する、アンインストール後にアプリデータを削除する、または明示された保持/圧縮規則が働くまで残ります。日次ログのローテーションは自動削除を意味しません。第三者とサポートサービスの保持は各サービスの方針に従います。

05 / 管理

利用者が選べること

  • 送信を望まないProviderやAIサービスを設定しない。
  • 必要に応じて読取り専用、Paper、Demo、Testnet、Simulatorを使用し、元サービスで認証情報を失効させる。
  • Web Gatewayの無効化、ブラウザーのログアウト、端末別セッション失効、パスワード変更、ローカルセッションストアの消去を行う。
  • テクニカルサポートの手順でローカル設定、DB、ログ、サイトの言語設定を削除する。
  • TrueFix Labsへ直接送信した個人情報へのアクセス・削除は当社へ連絡する。本人確認をお願いする場合があります。
TrueFixクラウドアカウントはありません

現行版はホスト型TrueFixアカウントを作成しないため、Google Playのウェブアカウント削除フローは適用されません。アカウント作成を導入する場合は配布前に本ポリシーと削除機能を更新します。

06 / 安全

セキュリティと未成年者

ユーザー限定権限、認証情報の伏字、スコープ付き認可、Web Refresh Tokenと端末指紋のハッシュ、短期間のAccess Token、セッション失効、Host/Origin検証、非loopback Web GatewayでのHTTPS必須化等を使用します。完全に安全な仕組みはないため、端末、設定、バックアップ、Provider認証情報を保護してください。

TrueFix Studioは専門的な金融ワークステーションで、未成年者向けではありません。未成年者の個人情報を意図的に求めません。利用するブローカー、取引所、ストア、法域の年齢・資格要件を満たす必要があります。
